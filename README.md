# Преферанс «Ленинградка»

Два мини-приложения на одном движке записи пули. Каждое — одна HTML-страница без сервера, открывается в браузере.

| Файл | Что это |
|---|---|
| `dist/tracker.html` | **Пулька Ленинградка** — запись пули для живой игры на 3–4 игрока: игры, мизер, распасы, вист / пас / полвиста / возврат виста, история с отменой, итоговый расчёт в вистах, рейтинг Эло и рекорды |
| `dist/game.html` | **Ленинградка за столом** — игра против ботов: раздача с прикупом, торговля, снос, заказ, вист, розыгрыш с проверкой хода, распасы, мизер |

## Устройство

- `src/engine.js` — запись раздачи, закрытие пули, расчёт (сумма итогов = 0), рейтинг Эло. Чистые функции без DOM.
- `src/cards.js` — колода, раздача, правила хода, оценка руки и решения ботов.
- `templates/*.html` — интерфейс; при сборке в них подставляется движок.

```
npm run build   # собрать dist/
npm test        # тесты движка и прогон полных пулек ботами (нужен playwright)
```

## Правила по умолчанию

Игры 6–10 в пулю: 2/4/6/8/10, мизер 10. Вист за взятку, гора за недобор и консоляция — удвоенная стоимость игры. Обязательные взятки вистующих: 4/2/1/1/0. Полвиста на 6-й и 7-й. Джентльменский вист: при ремизе висты делятся с пасующим. Распасы: 2, 4, 6 в гору за взятку. Выход из распасов: после первых — игра от 7-й, после вторых подряд — от 8-й, после третьих подряд — снова от 6-й. После сыгранной игры (или мизера) и после трёх распасов подряд счёт начинается заново: следующие распасы снова считаются первыми. Вчетвером сдающий не играет. Пуля каждому — 20; очко пули = 2 очка горы, очко горы = 10 вистов.

В трекере ставки меняются при создании пульки. Рейтинг хранится в браузере.
